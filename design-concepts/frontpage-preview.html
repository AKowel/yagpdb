About Albert

Albert is a multi-purpose Discord bot that quietly looks after your server. Moderation, custom commands, role menus, feeds, and more, all handled without fuss. The best way to see what Albert does is to add him to a server and look around for yourself.

Albert also keeps a watchful eye on the home server's media services, posting a live status embed, queue updates, and service notifications, so nobody has to go check manually.

Features

Automatic Moderator

Configurable rules — mute, kick, or ban after a set number of violations within a timeframe.

Custom Commands

Triggers, dynamic responses, aliases — set up automatic replies for whatever your server needs.

Server Stats

Member activity, messages per channel, online counts — with graphs on the control panel.

Media Watch

Live download-queue status, service health notifications, and presence updates for the home server.
